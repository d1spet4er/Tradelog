# TradeLog 📈

Дневник крипто-сделок с автоматической синхронизацией истории торгов с бирж. Приложение помогает трейдеру вести журнал позиций, анализировать результаты и хранить заметки по каждой сделке — без ручного ввода данных.

🔗 **Демо:** [tradelog-two-rho.vercel.app](https://tradelog-two-rho.vercel.app/)

## О проекте

TradeLog решает проблему ручного ведения трейдерского дневника: приложение подключается к API бирж, забирает историю сделок и группирует отдельные исполнения в позиции — с графиком, точками входа/выхода, заметками и тегами.

Проект был написан на React (после Vue 3) как учебный pet-проект и постепенно вырос в полноценное приложение с авторизацией, безопасным хранением API-ключей и дашбордом.

## Возможности

- 🔐 Авторизация через email/password, Google и Discord (Supabase Auth)
- 🔑 Безопасное хранение API-ключей бирж — шифрование через Supabase Edge Functions
- 🔄 Автоматическая синхронизация истории сделок с Binance и Bybit
- ✅ Проверка валидности ключей для 7 бирж: Binance, Bybit, OKX, MEXC, Gate, KuCoin, Bitget
- 📊 Дашборд с метриками, графиком активности и разбивкой по биржам
- 📓 Журнал сделок: группировка исполнений в позиции, свечной график с отметками входа/выхода, заметки и теги
- 🌗 Светлая/тёмная тема

## Стек технологий

- **Frontend:** React, Vite
- **Backend / Auth / DB:** Supabase (Postgres, Row Level Security, Edge Functions)
- **Деплой:** Vercel

## Установка и запуск

```bash
git clone https://github.com/d1spet4er/Tradelog.git
cd Tradelog
npm install
npm run dev
```

Для работы приложения потребуется свой проект Supabase — создайте `.env` файл со своими ключами (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`).
